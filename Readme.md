# F1 Betting System

A Formula 1 betting system developed as a personal project to learn and explore software development concepts.

## Project Structure

- **Betting_System/** - Core betting functionality
  - Betting types: Fastest lap, lap timing, podium, pole position, rain, and retirement bets
  - Helper utilities and bet settlement logic
- **Database/** - Database connectivity and SQL management
  - Connection handling
  - SQL loading utilities
- **Race_Info/** - Formula 1 race information management

- **User_API/** - API endpoints for user interactions

- **User_Management/** - User account and authorization logic

- **web_server/** - Flutter-based web interface
  - Cross-platform UI (iOS, Android, Web, Desktop)

## Getting Started

1. Make sure you have Go and Flutter installed
2. Clone the repository
3. Set up environment variables using `.env` files
4. Run database migrations
5. Start the server
